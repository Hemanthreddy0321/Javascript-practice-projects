# JavaScript Practice Projects

A collection of hands-on web development projects built to strengthen my practical skills in HTML, CSS, and JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM manipulation, event handling, arrays, and browser APIs)

## Projects

| Project | Description |
|---|---|
| Calculator | Performs basic arithmetic operations |
| To-Do List | Add, search, complete, and delete tasks |
| Digital Clock | Displays the current time |
| Stopwatch | Start, stop, and reset a timer |
| Quiz App | Multiple-choice questions with score tracking |
| Password Generator | Generates random passwords |
| Password Validator | Checks password strength and requirements |
| Weather App | Fetches weather information using an API |
| Shopping Cart | Manages products, quantities, and totals |
| Image Slider | Navigate between images |
| Expense Tracker | Add expenses and calculate totals |
| Notes App | Practice building a notes interface |
| Form Validation | Validates user input |
| Counter App | Practice DOM updates and event listeners |

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the desired project's HTML file in your browser.
4. For projects that use APIs, an internet connection may be required.

## Learning Goals

- Improve JavaScript fundamentals and DOM manipulation.
- Practise event handling and interactive UI development.
- Understand API requests and asynchronous JavaScript.
- Build a foundation for learning React.

## Future Improvements

- Improve responsive design and accessibility.
- Deploy selected projects online.
- Add features and improve code organization.
